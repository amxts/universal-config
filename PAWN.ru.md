# Config Core для Pawn-плагинов

[English](PAWN.md) | [Русский](PAWN.ru.md)

Config Core отдаёт Pawn-плагинам 28 нативов оригинального `universal_config.amxx` — `cfg_load_file`, `cfg_get_value`, `cfg_set_int` и остальные — с сигнатурами из его `universal_config.inc`, так что собранные `.amxx`-плагины (в том числе Pawn-плагины, работающие с Menu Core) работают без изменений.

Он заменяет `universal_config.amxx`: старый плагин закомментируйте в `plugins.ini`, два плагина не могут отдавать одни и те же нативы. Pawn-плагины оставляют `#include <universal_config>`; в пакете лежит `include/universal_config.inc`.

## Чем отличается от оригинала

- Нет ограничений Pawn: ключ и значение любой длины, секция хранит все записи, блоки вложены на любую глубину, загружается сколько угодно файлов.
- Число читается так, как его читает `parseFloat` (`1e5` — это 100000), и записывается как есть (`2.5`, а не `2.500000`).
